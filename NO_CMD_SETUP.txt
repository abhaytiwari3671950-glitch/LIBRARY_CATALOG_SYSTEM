LibraryFlow (no CMD): Double-click START_LIBRARYFLOW.vbs, NOT START_GUI.bat. It launches gui.py with pythonw.exe in the background. For a desktop icon, right-click the VBS > Show more options > Send to > Desktop (create shortcut). On desktop shortcut choose Properties > Shortcut > Change Icon > Browse and select LibraryFlow_Original_Icon.ico from this folder. Keep this project folder in its permanent location. If Python installed elsewhere, edit the pythonw path in the VBS file.
